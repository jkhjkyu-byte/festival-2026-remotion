# 180초 시네마틱 마스터

| 시간 | 장면 |
| --- | --- |
| 00:00–00:10 | 암전에서 금속 무대로 돌리 인. 행사명과 슬로건을 순차 공개 |
| 00:10–00:22 | 포스터 전시와 두 연구소 시상 일정. 날짜를 가장 큰 정보로 배치 |
| 00:22–00:40 | CW의 여덟 분야 소개. 항목마다 제목과 짧은 성과 설명 |
| 00:40–01:36 | CW 분야별 수상자 소개. 분야 내 대상이 있으면 금빛 무대로 전환. 마지막은 마일리지 크레딧 |
| 01:36–01:54 | MS의 여덟 분야 소개. CW와 다른 항목과 조형 배경을 사용 |
| 01:54–02:46 | MS 분야별 수상자 소개 및 대상. 마지막은 마일리지 크레딧 |
| 02:46–02:56 | 시상식에 참석해 퀴즈를 맞히면 상품이 있다는 참여 안내 |
| 02:56–03:00 | 타이틀 복귀와 암전 |

첨부 엑셀의 항목 소개는 상영 시간에 맞춰 축약했다. CW 49행, MS 37행의 수상 명단을 사용하며 수상자 이름, 공동 수상, 수상 등급과 팀명을 유지했다. 엑셀에서 팀명만 제시한 CW 7S 세 건은 팀을 수상 주체로 표시한다. 빈 수상 등급은 마일리지 크레딧에 그대로 반영했다. 기존 요청의 명칭인 `BP(혁신과제)`를 MS의 `BP_TCP`에 적용했다. 기존 특허·논문 순서와 마일리지 마지막 배치를 유지하고, 나머지는 연구소별 엑셀 순서다.

오프닝과 대상에 별도의 5초 MP4 프루프를 사용한다. 전체본의 분야별 대상은 3.6초로 배정하고, 인원이 많은 일반 수상은 읽기 시간에 비례해 배분했다. 한 페이지의 일반 수상은 최대 여덟 행이다. 마일리지 크레딧은 CW 11초(10행), MS 9초(7행)간 재생된다. 합성 음향은 기존 프로젝트에서 제작한 큐를 사용한다.

11:3 무대는 Three.js의 실제 공간과 카메라를 사용한다. 4초 무대 플레이트 여덟 개를 미리 렌더해 본편을 합성한다. 검토용 마스터는 1980×540이며 문자 레이어는 출력 크기에서 렌더링한다. 현장의 실제 LED 매핑과 재생 규격은 별도 확인이 필요하다.
