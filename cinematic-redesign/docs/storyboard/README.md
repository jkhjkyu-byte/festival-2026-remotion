# 2026 기술/혁신 FESTIVAL 스토리보드

## 콘셉트

**성과가 무대에 서는 순간.** 어둠 속에 켜진 작은 빛이 하나의 축으로 정렬되고, 행사명이 그 위에 자리 잡는다. 다음 시상 장면에서는 같은 축을 기준으로 부문명과 수상자 정보를 읽을 순서대로 보여준다. 기술을 상징하는 형태와 움직임은 무대의 집중도를 높이는 데 사용하고, 행사명과 수상자 이름은 정지한 화면에서 충분히 읽히게 한다.

관객은 공연장 앞줄부터 후방까지 분산되어 있고, 시상 멘트와 영상이 함께 진행된다고 가정한다. 행사명은 요청에 포함된 표기를 사용했다. 부문명, 수상자명, 로고와 진행 신호는 승인된 원고와 운영 큐시트가 도착하면 반영한다.

## 오프닝 초안

12초는 시사본 작업용 가정이다. 현장 큐와 승인된 음원이 정해지면 각 구간의 길이를 조정한다.

| 구간 | 화면과 연출 | 현장에서 확인할 것 |
| --- | --- | --- |
| 0–3초 | 어두운 바탕에서 한 줄의 빛이 화면을 가로지른다. 카메라와 빛의 움직임은 하나의 방향을 따른다. | LED 화면의 어두운 영역에서 선이 뭉개지는지, 객석에서 과한 밝기 변화가 있는지 확인한다. |
| 3–6초 | 선이 감속해 자리 잡으면 행사명이 드러난다. 제목 뒤 배경의 움직임도 함께 잦아든다. | 밝은 요소가 글자와 겹치는 순간이 있는지 확인한다. |
| 6–10초 | 2026 기술/혁신 FESTIVAL을 고정한다. 주요 정보가 가장 잘 읽히는 프레임을 이 구간에 둔다. | 객석 후방에서 한글과 영문을 한 번에 읽을 수 있는지 확인한다. |
| 10–12초 | 진행 멘트 직전에 배경을 정리한다. 정지 구간의 마지막 프레임을 대기 화면으로 사용할 수 있게 한다. | 운영자가 즉시 다음 클립을 재생하거나 현재 프레임을 유지할 수 있는지 확인한다. |

시상별 클립은 **부문명 표시 → 수상 정보 공개 → 정지 유지**의 순서를 따른다. 수상자명 공개는 진행 큐에 맞추고, 이름과 소속이 긴 사례로 줄바꿈과 표시 시간을 검토한다.

## 3초 테스트 컴포지션

테스트에서는 행사명과 기본 모션이 있는 짧은 클립으로 프로젝트 구동을 확인한다. 첫 프레임, 제목이 가장 또렷한 프레임, 마지막 프레임을 비교해 글자 잘림과 프레임 간 끊김을 확인한다. 실제 MP4에서는 해상도, 프레임 수, 코덱과 재생 여부를 기록한다. 최종 오프닝의 시간 배분과 시상 큐 검증은 현장 규격을 받은 뒤 별도로 진행한다.

## 디자인 착수와 검토

1. 행사 운영팀으로부터 LED 유효 가로·세로 해상도, 화면 비율, 플레이어의 코덱과 프레임률, 음향 연결, 좌석 배치, 접근성 또는 밝기 제약을 확인한다. 브랜드 담당자에게 로고·서체 사용 지침과 표기 원고를 받는다.
2. 오프닝의 제목 고정 프레임과 가장 긴 수상자명을 넣은 시상 카드 시안부터 제작한다. 이 두 화면에서 제목 계층, 안전 여백, 색 대비를 정리한 뒤 모션을 확장한다.
3. 작성자와 다른 검토자가 시네마틱 영상미, 타이포그래피 및 가독성, 기업 행사 적합성, 모션과 장면 연결, 기술적 안정성, 최종 상영 환경 적합성을 평가한다. 수정 전후의 프레임 또는 영상과 관점별 통과 여부를 `docs/reviews`에 남긴다.
