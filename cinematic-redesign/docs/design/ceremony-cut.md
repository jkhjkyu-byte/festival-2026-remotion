# 시상식 연출·균등 노출 수정판

첨부 참고본의 금속 근접, 원경, 정보 정착 구도를 따라 장면의 거리를 나눴다. 오래 사용하는 동일 무대 컷의 비중을 낮추고, 오프닝에서 새 금속 디테일과 넓은 홀을 공개한 다음 타이틀을 고정한다. 일반 시상은 좌우로 전환된 홀과 기존 무대 근경을 범주별로 교차 편집한다. 정보가 정착한 뒤에는 글과 배경을 안정시킨다. 결말은 진주빛 밝은 홀에서 어두운 시작과 다른 명도를 경험하게 한 뒤 암전한다.

| 구간 | 시간 | 연출 |
| --- | --- | --- |
| 오프닝 | 00:00–00:10 | 금속 근접 → 넓은 시상 홀 → 타이틀 홀드 |
| 일정 | 00:10–00:22 | 기존 전시와 시상 일정. 두 조직의 새 명칭 반영 |
| CW 소개·분야 | 00:22–00:58 | 레이다 소개 4초와 분야 설명 8개 × 4초 |
| CW 시상 | 00:58–01:54 | 일반·대상·마일리지 14페이지 × 4초 |
| 미사일시스템 소개·분야 | 01:54–02:30 | 원거리 발사 연출 4초와 분야 설명 8개 × 4초 |
| 미사일시스템 시상 | 02:30–03:22 | 일반·대상·마일리지 13페이지 × 4초 |
| 감사 | 03:22–03:30 | 금속 부품을 다루는 손과 “기술을 현실로 만든 모든 손길에 / 한 해 동안 고생 많으셨습니다.” |
| 퀴즈 | 03:30–03:40 | 선물 상자, 리본, 현장 퀴즈 안내 |
| 엔딩 | 03:40–03:44 | 밝은 마무리, 타이틀과 슬로건, 암전 |

분야 소개 16개와 수상 페이지 27개는 각각 30fps에서 120프레임이다. 대상이 있거나 한 화면에 담기 어려운 경우 해당 분야를 4초 페이지로 나눈다. 대상 10개에는 약 0.8초 트로피 근접·풀백, 빛의 스윕과 합성 타격음, 등급·분야·이름 공개를 배정한다. 이름은 약 0.87초에 정착해 페이지 끝까지 3초 이상 표시된다. 마일리지는 스크롤 없이 표시한다. 수상 항목 86건, 공동 수상, 멘토·멘티 표기, 날짜와 장소를 유지했다.

화면과 일정에는 `CW생산본부`, `미사일시스템생산본부`를 사용한다. 금속 근접, 홀, 트로피, 작업자의 손과 밝은 피날레는 이 영상용으로 생성한 이미지다. 카메라 변위와 컷, 모션 라이트를 합성했으며 사용자가 보낸 원본 영상은 편집 자산에 포함하지 않았다.
