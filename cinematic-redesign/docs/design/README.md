# 2026 기술/혁신 FESTIVAL 아트 디렉션

아래 스타일 프레임은 디자인 제작을 시작하기 위한 제안이다. 1920 × 1080, 16:9를 시안 좌표계로 사용한다. 상영본의 해상도, 화면 비율과 프레임레이트는 현장의 송출 규격을 받은 뒤 확정한다.

## 시각 방향

‘성과가 무대에 서는 순간’을 시각화한다. 잉크빛 남색 바탕에 얇은 청록색 광선이 한 축을 따라 열리면서 행사명과 수상 정보가 드러난다. 장면 순서와 시간은 스토리보드의 시안을 따른다. [스토리보드](../storyboard/README.md) 청록은 기술과 탐색을, 차분한 금색은 시상 순간을 표현한다. 선과 입자의 밀도는 화면 바깥쪽에서 높이고 글자 뒤는 평탄한 명도로 유지한다. 공식 브랜드 자료가 제공되면 색상과 로고 처리 기준을 대조해 승인받는다.

| 역할 | sRGB 시작값 | 적용 |
| --- | --- | --- |
| 배경 | `#0A1020` | 무대에 가까운 남색. 암부를 현장 테스트에서 조절한다. |
| 문자 배경 | `#111F35` | 제목과 이름 뒤 명도 기준. 그래픽이 겹치는 프레임에도 유지한다. |
| 주 문자 | `#F4F7FC` | 행사명, 부문명, 수상자 이름 |
| 보조 문자 | `#BCCADC` | 소속, 소제목 |
| 기술 강조 | `#62DDE8` | 광선, 윤곽, 장면 전환 |
| 시상 강조 | `#E9BE78` | 수상자 공개의 테두리 또는 짧은 하이라이트 |

작업용 sRGB 색상에서 주 문자와 문자 배경의 명암비는 약 15.4:1, 보조 문자와 문자 배경은 약 9.9:1이다. 합성 효과가 적용된 후에는 최종 프레임의 실제 문자와 배경을 다시 측정한다. 이 값은 LED 밝기, 무대 조명과 객석 거리의 영향을 반영하지 않으므로 현장에서 별도로 읽기 시험을 한다.

## 제안 스타일 프레임

| 프레임 | 레이아웃 | 검토할 부분 |
| --- | --- | --- |
| 오프닝 | 왼쪽 안전선에서 `2026 기술/혁신`과 `FESTIVAL`을 두 줄로 배치한다. 오른쪽에는 한 점에서 펼쳐지는 청록색 광선을 사용한다. | 연도, 행사명, 영문 표기를 멀리서 즉시 구분할 수 있는지 확인한다. |
| 부문 안내 | 작은 시상 정보와 한두 줄의 부문명을 왼쪽에 배치한다. 오른쪽 그래픽은 선의 방향을 정돈해 다음 공개를 예고한다. | 최장 부문명으로 줄바꿈을 점검한다. 수상자 정보가 들어오기 전까지 명확히 읽히는 홀드를 둔다. |
| 수상자 공개 | 이름을 가장 큰 글자로 배치하고, 소속은 한 단계 낮은 크기로 제공한다. 짧은 금색 하이라이트를 이름 영역 바깥에 배치한다. | 한글·영문 이름, 긴 소속명, 팀 수상과 공동 수상을 각각 검토한다. 행사 측이 확인한 이름 표기를 유지하고 공간이 모자라면 줄바꿈과 글자 크기를 먼저 조정한다. |
| 엔딩 | 빛의 움직임을 줄여 행사명 또는 승인된 로고에 시선을 모은다. | 로고 규정과 최소 여백을 확인하고 진행자 큐를 위한 홀드 길이를 합의한다. |

## 글자와 배치

- 시안에서 화면 양쪽과 상하에 각각 10%의 문자 안전 여백을 둔다. 1920 × 1080에서는 좌우 192 px, 상하 108 px다. LED 분할선이나 실제 유효 표시 영역이 확인되면 이 값을 조정한다.
- 1080p 타이포그래피의 시작값은 행사 제목 104 px, 수상자 이름 88 px, 보조 정보 44 px다. 제목과 이름은 굵게, 보조 정보는 중간 굵기로 설계한다. 가장 긴 실제 문자열과 혼합 문자 샘플을 최종 픽셀 크기로 검수한다.
- 한글과 라틴 글리프가 일관적인 **Noto Sans KR**를 초기 후보로 삼는다. 사용할 파일의 SIL Open Font License와 버전을 확인하고, 권한이 확인되면 고정된 자산을 렌더 환경에 포함한다. 폰트 파일은 렌더 전에 준비한다. [Noto CJK 공식 저장소](https://github.com/notofonts/noto-cjk)
- 광선, 입자와 금색 하이라이트가 글자 위로 지나갈 때 읽기 순서가 흐트러지지 않는지 확인한다. 규칙적인 고휘도 점멸과 컷마다 반복되는 전면 플래시를 피한다.

## 제작과 승인

1. 오프닝, 부문 안내, 수상자 공개, 엔딩의 키 프레임을 원본 크기로 만든다. 화면 가장자리에는 안전선 가이드를 작업용으로만 표시한다.
2. 행사 로고 원본, 공식 색상과 서체, 부문과 수상자 표기 규칙, 영상에 쓸 로고·사진·음원의 이용 범위, LED 장비 해상도와 송출 사양을 확보한다.
3. 외부 자산에는 원출처, 저작자 또는 공급자, 버전, 라이선스나 계약, 행사 상영 및 납품 허용 범위를 기록한다. 승인본과 라이선스 사본을 함께 보관한다. 생성형 시안을 쓰는 경우 제작 도구, 모델, 프롬프트와 사용 당시 약관을 기록하고 기업 행사 사용 승인을 받는다.
4. 디자인 초안을 다른 역할의 검토자에게 넘겨 후방 객석 크기에서 이름을 읽고, 장면 전환 전후의 프레임에서 가독성을 확인하게 한다. 관찰된 문제와 수정 프레임, 재검토 결과를 `docs/reviews`에 남긴다.
5. 승인본은 실제 상영 장비에서 안전선, 암부, 색 번짐, 밝기, 진행 큐 시점을 확인한다. 장비와 승인 자산이 필요한 항목은 후속 검수로 남긴다.
