# 수상 순서 수정판 독립 검수

2026-11-22, 기존 시상식 확장판과 수정판의 수상 데이터·페이지·프레임·음향을 대조한다. 수상 명단 원문은 영상 데이터에서 확인하고, 검수 기록에는 항목 수와 수정 범위를 남긴다.

## 확인할 변경

- CW생산본부 7S 낭비제거활동 대상의 이름을 요청대로 김태호로 바꾼다. 해당 항목의 팀과 등급, 나머지 수상 항목과 행사 정보는 이전 버전을 따른다.
- 7S 개인 수상 6개 항목은 한 4초 페이지에 함께 표시한다. 팀 수상 3개 항목은 원래 등급을 표시해 별도 4초 페이지에 함께 배치한다. 대상은 독립된 4초 페이지다.
- 모든 일반 수상 페이지를 `최우수 → 우수 → 장려 → 기타 등급`으로 정렬한다. 같은 등급은 데이터 순서를 유지한다. 두 열을 사용하는 경우 왼쪽 위부터 아래로 진행한 뒤 오른쪽 위로 넘어간다. 마일리지에는 별도 등급을 붙이지 않는다.
- 교체한 대상 음향이 모든 대상 페이지에서 들리는지 확인한다. 일반·마일리지 화면의 순서와 가독성, 감사 인사 이후 퀴즈와 엔딩으로 이어지는 구조도 유지되는지 본다.

## 데이터·음향 소스 검증

- `fb497e4`의 명단과 현재 데이터를 독립 대조했다. 변경은 7S 대상 한 항목의 이름뿐이며 소속 `기계기술2팀`, 등급과 다른 수상 항목은 동일했다. CW 49개, MS 37개와 본부별 대상 5개를 확인했다.
- 7S의 세 페이지는 2820·2940·3060프레임에 시작한다. 개인 6개, 팀 3개, 대상 1개가 각 페이지에 배정됐다. 팀 페이지의 기존 등급은 순서대로 `지속실천 우수팀`, `최다 제출팀`, `다각화 제안 우수팀`이다.
- 양 본부의 각 분야별 일반 순서를 이전 행 번호로 동률을 푸는 독립 정렬식과 비교했다. 일반 페이지 15개와 대상 10개, 마일리지 2개가 각각 120프레임이다. 일반 화면의 최대 8번째 행은 26프레임까지 정착하도록 설정돼 있다. 본부별 마지막 마일리지는 등급을 추가하지 않았다.

## 사전 프레임 검토

`out/awards-order/proofs`의 열 프레임을 독립 검토했다. 일반상 예시 2105·2115·2150번과 7S의 2824·2828·2835번은 먼저 왼쪽 열의 위에서 아래로, 그다음 오른쪽으로 이름이 차례로 나타났다. 2872번에서 7S 개인 여섯 항목, 2992번에서 팀 세 항목과 이전 등급, 3115번에서 김태호와 기계기술2팀을 확인했다. 5260번의 MS 일반 시상 예시에서는 `최우수`, `우수`, `장려`가 양 열의 읽기 순서에 맞게 놓였다. 사전 프레임의 등급과 공동 이름에 잘림은 발견되지 않았다.
