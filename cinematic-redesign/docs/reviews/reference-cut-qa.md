# 참고 영상 반영판 검수

2026-11-22. QA Director가 첨부 자료, 기존 시네마틱 마스터와 수상 데이터를 대조했다. 최종 파일의 기술 검증과 표본 프레임 검토는 구현 담당자가 이어서 수행했다.

## 제작 기준과 데이터 확인

- 첨부 참고 영상의 12개 시점에서 짧은 형상·조명 컷과 긴 문안 유지 구간의 대비, 남색·금색 시상부와 밝은 퀴즈 마무리를 확인했다. 검토 대상은 그 리듬과 명암을 현재 행사 정보에 맞춰 해석한 180초 영상이다.
- `src/data/award-roster.ts`는 이전 검수 커밋과 동일하다. 기존 워크북 대조 기록의 CW 49개와 MS 37개 수상 항목을 이어받았다. [워크북 대조 근거](cinematic-redesign-qa.md)
- 실제 명단을 입력해 멘토·멘티 표기 함수를 독립 시험했다. CW의 해당 항목 3개 모두 `멘토(…)/멘티(…)` 형식으로 그룹화되고, 역할별 이름은 기존 순서와 값이 유지됐다. MS와 다른 분야에는 이 형식이 적용되지 않았다.

## 검토 기준

| 관점 | 확인 항목 |
| --- | --- |
| 영상미 | 오프닝의 짧은 도입과 이름 공개의 여유, 금빛 대상의 집중, CW 안테나 스캔과 MS 원거리 상승 실루엣, 밝은 선물 장면의 대비 |
| 타이포그래피와 가독성 | 멘토와 멘티의 구분, 일정과 한글 제목, CW·MS 마일리지의 화면 내 고정 위치, 퀴즈 안내의 짧은 문장 |
| 기업 행사 적합성 | 수상 항목 86개, 분야와 등급, 행사명과 일정, 현장 퀴즈의 짧은 안내와 선물 모티프 |
| 모션과 장면 연결 | 각 영역의 속도 변화, 레이더 스윕과 원거리 연출의 전후, 선물이 열리는 순간과 안내의 정착, 중간 암전 또는 잘못된 컷 |
| 기술 안정성 | 180초, 1980 × 540, 11:3, 30 fps, 5,400프레임, H.264 BT.709, AAC와 전체 디코딩 |
| 상영 환경 | 실제 LED 매핑, 어두운 방산 장면의 명암, 객석에서 읽히는 명단과 음향 큐 |

## 최종 MP4 결과

- `npm run lint`, `npm run build`와 데이터 검증을 통과했다. 두 연구소의 86개 수상 항목과 대상 10개, 일정과 180초 시간표는 기존 버전과 일치했다.
- 1980×540, 30fps, 180초의 H.264 BT.709 영상 5,400프레임과 AAC 스테레오를 끝까지 디코딩했다. 01:36–01:39 부근의 발사 연출과 02:47–02:51 퀴즈 구간을 시킹해 재생했다.
- 최종 파일에서 CW 마일리지 2620·2760번 프레임과 MS 마일리지 4760·4920번 프레임을 비교했다. 각 화면은 디코딩 후 회색조 축소본에서도 픽셀이 일치했다. 시작·종료 프레임은 암전이며, 0.25초 이상의 중간 암전은 검출되지 않았다.
- 최종 영상에서 레이다 인트로, MS 원거리 발사 연출, 멘토·멘티 세 조의 역할 표기, 선물 상자와 짧은 퀴즈 안내를 확인했다. 원경과 근경, 분야 설명의 좌우 교대, 시상부와 퀴즈의 명도 차이를 [최종 프레임 모음](../../deliverables/reference-cut/scene-review.jpg)에 기록했다.
- 파일 SHA-256은 `771a8849494cb5802cb32081dc48151106fe9fd434e96c81c7c856ef1476ccdd`다. 실제 LED의 픽셀 매핑과 객석에서의 글자·음향은 현장 확인 범위다.
