# 독립 검토 및 상영 승인

## 단계별 검토

1. 제작 담당자가 초안을 작성하고 버전, 의도, 검증 대상 및 근거 파일을 기록한다.
2. QA Director 또는 초안 작성에 참여하지 않은 에이전트가 아래 여섯 기준으로 평가한다. 한 사람이 여러 역할을 맡는 경우에는 제작과 검토를 별도 패스로 진행하고 검토 방식과 한계를 기록한다.
3. 각 문제에는 기준, 장면 또는 프레임 번호, 재현 방법, 심각도, 담당자를 기록한다. 내용 오류, 화면 잘림, 재생 실패를 발견하면 해당 단계의 승인을 보류한다.
4. 담당자가 수정하고 변경된 파일 또는 프레임을 제출한다.
5. 검토자가 동일한 조건에서 문제를 다시 확인하고 영향을 받는 앞뒤 장면도 검토한다.
6. 기준별로 통과, 실패, 보류 중 하나를 기록한다. 보류 항목에는 검증에 필요한 입력이나 장비를 명시한다. 렌더 파일이 바뀌면 최종 납품본의 재생 증거를 갱신한다.

| 단계 | 제출 근거 | 다음 단계 진입 기준 |
| --- | --- | --- |
| 리서치 | 출처, 검토한 라이선스, 적용 가능한 표현 원칙, 행사 조건 | 참고 근거와 사용 권한 확인. 미확정 행사 조건은 담당자와 확인 시점 기록 |
| 스토리보드 | 장면별 역할, 타이밍, 화면 문구, 시선 이동, 전환 | 행사 순서와 문구 승인. 정보가 읽힐 유지 구간 확보 |
| 디자인 | 실제 문구가 들어간 스타일 프레임, 폰트 및 에셋 출처, 안전 영역 | 축소 화면에서 가독성 확인. 로고, 수상자 이름, 색상 및 사용 권한 검토 |
| 모션 및 구현 | 리뷰용 MP4, 대표 프레임과 전환 경계, 검사 명령과 결과 | 정상 속도 재생 및 프레임 검토. 기술 검사와 회귀 검사 통과 |
| 상영 | 납품 MP4, 미디어 정보, 행사장 플레이어와 스크린 테스트 기록 | 확정 행사장 규격과 일치하고 운영자가 실제 장비로 재생 승인 |

## 여섯 가지 검증 기준

| 관점 | 확인 내용과 근거 |
| --- | --- |
| 시네마틱 영상미 | 대표 프레임에서 초점, 명암, 색, 화면 깊이의 일관성을 살핀다. 조명과 장식이 타이틀이나 수상자 정보보다 강한지 정상 속도 재생과 정지 프레임에서 확인한다. |
| 타이포그래피 및 가독성 | 한글 글리프, 긴 이름, 줄바꿈, 배경과 글자의 대비를 확인한다. 시작·중간·끝과 전환 경계를 샘플링하고 축소 화면에서 유지 구간 동안 문구를 읽는다. 실행 검증용 샘플에서는 필수 정보에 각 변의 5% 이상 여백을 요구한다. 상영 시안에는 아트 디렉션의 임시 10% 문자 여백을 적용하고, 현장 유효 화면을 확인한 뒤 조정한다. |
| 기업 행사 적합성 | 행사명, 연도, 수상 부문, 성명, 소속, 로고를 승인 원고와 비교한다. 어조, 브랜드 규정, 저작권 및 초상권도 확인한다. |
| 모션과 장면 연결 | 정상 속도 재생으로 카메라, 이징, 진입과 정착의 리듬을 확인한다. 전환 전후 프레임을 비교해 깜빡임, 잘림, 정보 중첩, 의도하지 않은 순간 이동을 찾는다. |
| 기술적 안정성 | 린트·타입 검사, Studio 실행, Chromium 렌더를 확인한다. `ffprobe`에서 코덱, 픽셀 포맷, 해상도, FPS, 프레임 수, 길이와 오디오 스트림을 비교하고 전체 디코딩으로 손상 프레임을 점검한다. 주요 프레임의 상태는 같은 입력과 프레임으로 재현할 수 있어야 한다. |
| 최종 상영 환경 적합성 | 운영자에게 화면 비율, 해상도, 주사율, 색 범위, 입력 코덱, 음향 및 재생 큐를 확인한다. 최종 파일을 실제 재생 장비로 상영해 화면 매핑, 가장 먼 좌석에서의 가독성, 음량, 첫 프레임과 종료 타이밍을 승인받는다. |

## 기록 양식

각 검토는 버전 또는 커밋, 산출물 경로, 컴포지션 ID, 출력 사양, 검사 일시, 제작 및 검토 역할, 여섯 기준별 결과, 결함과 수정·재평가 결과, 다음 승인 조건을 기록한다. 명령 출력으로 확인한 기술 지표와 화면을 보고 판단한 시각 평가는 각각 근거를 남긴다. 검증용 샘플에는 실제 장소나 납품본이 있어야 수행할 수 있는 항목을 보류로 기록한다.
